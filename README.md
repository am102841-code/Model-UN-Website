<h2><code>🌐 ABOUT THE PROJECT</code></h2>

The Model UN Website is a web project designed to provide students with a central place to learn about **Model United Nations**, explore committees and countries, and access useful resources for conferences and preparation.

The goal is to make Model UN information easier to find and organize in one website.

```text
LEARN  →  PREPARE  →  DEBATE  →  COLLABORATE
```

---

<h2><code>🚀 CURRENT FEATURES</code></h2>

### 🌎 Model UN Information

The website provides information about Model UN and helps students understand the basic structure of conferences and committees.

### 📚 Resources

The website is designed to organize useful Model UN resources in one place.

Potential resources include:

* Committee information
* Country information
* Research resources
* Position paper guidance
* Rules and procedures
* Debate preparation

### 💻 Web Interface

The website uses a structured interface to organize different sections of Model UN information.

The project is being developed with a focus on making the information **clear, accessible, and easy to navigate**.
